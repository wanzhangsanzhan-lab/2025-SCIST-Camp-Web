Core Tracks 兩大核心主軸

Competitive Programming

Algorithms 演算法

從基礎語法到資料結構，目標是培養能獨立解決 APCS 實作題的能力。

  • C++ 基礎語法：變數、迴圈、陣列與函式，建立紮實程式邏輯。
  • 資料結構：Vector, Stack, Queue, Set/Map 應用解析。
  • 演算法策略：遞迴 (Recursion)、動態規劃 (DP)、貪婪法則 (Greedy)。
  • 檢定目標：APCS 觀念 4 級分 / 實作 3 級分以上。
CTF / Cybersecurity

Information Security 資訊安全

學習駭客思維與防禦技術，以參與 CTF 搶旗賽與 AIS3 為目標。

  • Web Security：網頁漏洞分析 (SQL Injection, XSS) 與防護。
  • Cryptography：古典密碼學、現代加密與編碼原理 (Base64, RSA)。
  • Reverse & Pwn：逆向工程入門，分析二進制檔案漏洞。
  • 競賽實戰：MyFirstCTF 賽制介紹與解題技巧實作。

FAQ 常見問題

Q: 完全沒有程式基礎可以參加嗎？
A: 可以！我們的「演算法組」會從最基礎的 C++ 語法教起，非常適合新手入門。
Q: 參加這個營隊對 APCS 有幫助嗎？
A: 絕對有幫助。SCIST 的演算法課程設計緊扣 APCS 檢定內容，我們的目標是協助學員在觀念與實作題上都能拿到好成績。
Q: 資安組需要很強的程式能力嗎？
A: 不需要很高深的程式能力，但建議對電腦系統運作有好奇心。我們會從 Linux 指令與網頁原理開始引導。
Q: 需要自備電腦嗎？
A: 是的，請務必自備筆記型電腦（Windows/Mac/Linux 皆可）。現場會提供 Wi-Fi 與延長線。
